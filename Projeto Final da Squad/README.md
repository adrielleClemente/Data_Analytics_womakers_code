# 📊 Previsão de Bullying - Projeto Final da Squad

Projeto organizado em grupo, nós da squad Dorothy Vaughan recebemos o desafio de entregar dois grandes objetivos: Fazer uma **análise de dados** e um **modelo de regressão logística**.

### 📌 Descrição

Este repositório contém a análise e modelagem preditiva para a previsão de bullying com base em diferentes fatores. O objetivo é explorar padrões nos dados, aplicar técnicas estatísticas e construir um modelo de aprendizado de máquina para identificar possíveis casos de bullying.

### ⬇️ Dataset
- [Bullying_2018](https://drive.google.com/uc?id=1Efe6xU-mbhKYxBhrVEaepOoqlSSkDFkm)
